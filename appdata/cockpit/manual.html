🛠️ Universal Family Fail-Safe Diagnostics

Review these three simple checks if a family member encounters an unexpected layout error panel on screen:

  • Symptom: METRIC DROP (Red Disconnect Header Flashing)
    Resolution: A background tracking container has gone offline or dropped out of memory space. Open your terminal screen, type cd ~/citadel && docker compose restart, and hit Enter to recycle the network pipelines cleanly [INDEX].
  • Symptom: 502 Bad Gateway Error Web Block
    Resolution: The central Nginx gateway router is healthy, but the corresponding backend tool app script hasn't answered the door yet [INDEX]. Give the container engine 30 to 45 seconds to finish its initialization boot pass, then hold down Ctrl and tap F5 on your keyboard to hard refresh the cache [INDEX].
  • Symptom: Web Browser Page Returns "File Not Found"
    Resolution: The browser is looking for a local system path directory route instead of the true server loopback channel. Ensure the address bar reads exactly: http://localhost:8085 [INDEX].
