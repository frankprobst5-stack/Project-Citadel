# Where a Flash game goes

Drop a real, properly-licensed `.swf` file here and name it `game.swf` —
the Arcade's "SWF Player" button will pick it up automatically the next
time the page loads, no code changes needed.

Only put something here that's actually yours to use: something you made
yourself, or a game its own creator explicitly released under an open/
public-domain license. See `THIRD-PARTY-NOTICES.md` at the top of this
project for the same standard applied to everything else Cloud9 bundles —
add a line there too once you add a real game here, naming the game and
its actual license.
